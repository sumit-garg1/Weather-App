# Weather Analysis & Report Generation

## 📌 Objective

A Python CLI tool that:
- Fetches current weather data for a list of cities
- Stores the data locally in JSON format
- Analyzes the weather data to provide basic insights
- Generates a clean, formatted report

---

## How to Run the Project

### 1. Clone the Repository or Extract ZIP

If from GitHub:
```bash
https://github.com/sumit-garg1/Weather-App
cd your-repo-name

2. Install Dependencies
pip install -r requirements.txt


3. Set the OpenWeatherMap API Key
set OPENWEATHER_API_KEY=your_api_key_here

4. Run the Script
python main.py


5.Sample Insights in Report

Average temperature across all cities
Highest and lowest temperatures
Humidity range
City-wise summary

6.Assumptions Made
API key is securely stored using environment variables.
Internet connection is required while fetching the data.
Basic insights only – advanced ML/statistical analysis is not included.
